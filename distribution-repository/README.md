# WarMusic Releases

This repository distributes official Windows builds of WarMusic and provides public issue reporting. Application source is maintained separately and is not licensed or distributed by this repository.

Download packages only from this repository's Releases page. WarMusic supports Windows 11 x64 and requires VB-CABLE to be installed separately.

Every release includes:

- a self-contained single-file Windows x64 EXE;
- a self-contained Windows x64 MSI;
- a self-contained portable ZIP;
- SHA-256 checksums; and
- build provenance identifying the private-source commit and build run.

Unsigned stable and prerelease downloads may produce a Windows reputation warning. Verify downloads against `SHA256SUMS.txt`. WarMusic has no telemetry or automatic updater.
