# WarMusic privacy

WarMusic processes audio locally on the Windows PC where it is running.

- It has no telemetry, analytics, advertising, accounts, or cloud service.
- It does not upload microphone audio, application audio, local clips, settings, or diagnostics.
- Settings, imported sounds, recordings, and diagnostics remain in the selected local data folder.
- Choosing **Start with Windows** creates a per-user Windows startup entry only.

WarMusic can open the project documentation, the Windows sound settings page, and the VB-CABLE website when the user explicitly selects those actions. It does not check for or install updates automatically.
